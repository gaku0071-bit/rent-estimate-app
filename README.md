# 賃貸初期費用計算アプリ

PDFの物件概要書を読み込み、個人宛・法人宛の初期費用見積をA4サイズで印刷できるWebアプリです。

## 起動

```bash
python3 server.py 8787
```

PCのブラウザでは `http://127.0.0.1:8787` を開きます。

スマートフォンで使う場合は、PCとスマートフォンを同じWi-Fiに接続し、起動時に表示される `スマホ用URL` をスマートフォンのブラウザで開きます。

## PCなしでスマホから使う場合

スマートフォン単体で使うには、このアプリをRender、Railway、Fly.ioなどのクラウドにデプロイします。クラウド上でPythonサーバーが動くため、PCを起動していなくてもスマートフォンからURLで利用できます。

このフォルダにはデプロイ用の `requirements.txt`、`Procfile`、`render.yaml` を含めています。Renderでは新規Web Serviceとしてこのフォルダを接続し、Build Commandを `pip install -r requirements.txt`、Start Commandを `python server.py` にします。

スマートフォンのブラウザで公開URLを開いたあと、ホーム画面に追加するとアプリのように起動できます。

## 使い方

1. `PDF読込` から物件概要PDFを選択します。
2. 読み取られた物件情報と費用項目を必要に応じて編集します。
3. `個人宛` / `法人宛` を切り替えます。
4. 入居開始日を入れると月末までの日割日数が自動計算されます。必要に応じて駐車場、エアコン洗浄料なども調整します。
5. `A4印刷` からPDF保存または印刷します。

保証会社の初回保証料は、PDFから読み取った月額系の項目を候補として表示し、チェックされた対象項目の合計に料率を掛けて自動計算します。初期状態では個人宛は賃料、共益費・管理費、町内会費、24時間管理料、給湯器リース料を対象にし、法人宛では大手法人不要の条件に合わせて0円にしています。

PDFごとの項目名の違いにも一部対応しています。たとえば `室内清掃費用` / `退去時清掃費`、`カギ交換費用` / `シリンダー交換料`、`24時間管理料` / `24時間管理費` / `夜間サポート` は同じ費用枠として読み込み、見積上はPDFに近い名称で表示します。保証会社条件に `初回保証料30,000円` のような固定額がある場合は、その金額を優先します。

PDF内で項目名が改行される場合にも対応しています。たとえば `ハウ` と `スクリーニング料` が別行に分かれていても、`ハウスクリーニング料` として読み込みます。

費用項目には支払時期を持たせています。PDFに `退去時` とある費用は、見積表には表示しますが初期費用の合計から除外します。
退去時払いの費用は初期費用表とは別に `退去時費用` 枠へまとめ、一覧と合計額を表示します。

PDFに `契約時または退去時` や `退去時払い可` のような表記がある費用は、支払時期を `要選択` として表示します。選択が終わるまでは合計から除外し、費用項目欄に注意を表示します。

入居開始日が15日以降の場合は、入居月の日割に加えて翌月分の月額費用を見積に含めます。14日以前の場合は、入居月の日割のみを含めます。
24時間管理料・24時間管理費と町内会費は日割せず、入居月分を満額の月額請求として見積に含めます。
駐車場を含める場合は、賃料と同じく入居月の日割と15日以降の翌月分を見積に含めます。

仲介手数料は、賃料1か月分 + 消費税10%として自動計算します。

フリーレント期間を入力すると、その期間に重なる賃料と共益費・管理費を控除します。

月額費用は別枠で一覧と合計額を表示します。保証会社の `月額保証料` や `月額手数料` も読み取れる場合は月額費用に含めます。

初期費用表は、敷金、礼金、日割賃料、翌月賃料、清掃料、鍵交換費用、保険料、保証料、仲介手数料の順に近い形で表示します。
